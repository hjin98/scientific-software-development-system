## Selector, retirement and settlement assessment

Manual §3.4 fixes the integrated-result review target; §10.3 prohibits dispatching an answered judgment again; §10.4 requires the principal's route for item-level adversity naming no part; §13.7 keeps discharged parts required and makes named-part adversity a veto on those parts; §16.5 carries earlier objections; §16.7 requires the relevant review outcomes in the principal's working state. These are distinct obligations. Merely displaying an OPEN state would not satisfy them.

`ItemObligation._named_parts` resolves strict integer indices against integrations named in the review target's `changes`, across `_all_parts`. It requires exactly one judged part for each adverse finding. `_branch` follows obligation identities through re-partitions; subtracting replaced internal nodes leaves the branch's unreplaced parts, all of which must remain required. The current required set is not substituted for the review's historical judged set. The repeated-index discriminator and historical mutation reject that substitution.

`_objections` retires the local named-part obligation only after every required descendant re-integrates after the review. `_objections_naming` applies the veto to each unredone required descendant. For a no-part objection, both the review's admission position and its target's integration position must advance: a different digest alone is insufficient. `Items.entry_positions` is bounded to the evaluated history prefix. The older/same/newer controls confirm this distinction. This local routing retirement does not rewrite the judgment layer's objection, judged content, supersession or relief rules.

**Changing from part to no-part is admissible.** The target and judged part do not change. What changes is whether the current execution still has a complete required branch that can answer every finding. A whole partition dropping some of that branch removes that route; failing safe to the principal preserves the finding. Continuing to treat it as a named-part obligation would reproduce N-1 or N-a. This is a state-relative routing classification, not a reassignment of `W(j)` or a claim that the finding was resolved.

**A retired objection returning is not a Phase E blocker.** I reproduced the §6 behavior: redo retires the named-part routing veto; later drift and a whole partition drop that part; the old review becomes no-part again. The item remains OPEN with required replacement work. After that work integrates, the next principal decision and carried review are derived, and the decision brief names the returning objection. No tested answer is revoked. The behavior can cause unnecessary coordination, but errs toward review. A preliminary version with overlapping replacement scopes instead reproduced the already disclosed kept-part drift; the corrected disjoint-scope control isolates return from overlap.

**Reviving a dropped part remains Phase F's Admission obligation.** It requires counting an answer to an obsolete, no-longer-derived part decision. The handoff and §6 expressly leave that refusal to Admission. Phase E's structural interpretation of such a record is not acceptance of its admissibility. No authorized history requiring such an answer was used to justify this PASS; Phase F must refuse it before claiming assembled behavior.

The recursive `_partition_settled` rule is unchanged by this delta. Its integration history only accumulates; every required replacement branch must finish, and a dropped branch no longer holds a decision hostage. Current `SettledPartition` tests rerun B-1, B-2, S-1, C-1, the dropped-branch control, and the answered continuation. No decision retraction or premature settlement survived. `_named_parts` can cause historical required-part evaluation, but I found no same-state recursion: `discharged_at` evaluates the prefix before the later partition. Its repeated historical work does have the scaling cost reported below.
